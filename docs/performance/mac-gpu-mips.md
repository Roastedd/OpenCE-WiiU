# GPU mip filtering rebased onto de64efde

Branch: `codex/gpu-mip-rebase-20261031`, based on
`de64efdea42b1543bc695c67dbdcf8afbd639859`. Host-only work, October 31, 2026.
No console connection, deployment, push or merge into `wiiu-big-endian` was
performed. The earlier implementation in `scratch/opence-gpu-mip-20261031`
was preserved unchanged.

## Result

The independently written GPU filter is integrated with the current renderer,
including its font, dynamic-resolution and per-draw work. Its only textual
rebase conflict was resolved by retaining both the new font header and the
mip-helper header. The rebased full Wii U build uses `--wiiu-lto`, passes the
object instruction gates, links with zero missing stubs, and is accepted by
`readrpl`. No simulation code or network protocol changed.

The GPU path remains **off by default**. Startup `gpu_test.txt` mode 2 runs
40 byte checks across 20 queued production-helper derives and enables the
GPU filter for that run only after success. Mode 3 enables it without test
readbacks for a subsequent matched timing run. Mode 0 retains the CPU
reference; mode 1 retains the existing frame-replay test.

Each successful steady-state GPU derivation replaces the CPU reference's
explicit completion wait, readback and byte filter with two ordered GPU
copies and one draw. Replaced scratch storage still follows the existing
retirement policy, which can wait when its deferred queue fills. This is
an operation-count change, **not a measured Wii U speedup**. GPU execution
and scene call frequency cannot be measured on the host. Correcting the
cache policy can also restore previously omitted work.

## Filtering and ownership

The fixed shader implements the existing CPU byte-space average, including
half-up rounding per channel, alpha, intermediate rounding, floor-halved
odd dimensions, and repeated singleton dimensions. It uses four exact
texel fetches. A source-level copy into a one-level scratch texture avoids
assuming view-relative LOD behavior; a separate color scratch target avoids
read/write feedback. The quad is immutable. Scratch allocation and shader
validation finish before context mutation; failure retains the CPU fallback.

The Mac shader corpus motivated this investigation. No commercial Mac
shader or machine code was copied; the filter implements our existing CPU
contract independently. The Mac's GPU and PowerPC instructions are not
treated as Wii U performance evidence.

## Cache-state correction

The original refresh policy on this base can confuse a generated stamp
with a later explicit target's stamp. It can also leave a descendant stale
when a level changes provenance without changing that integer. The branch
requires explicit provenance before reusing an explicit stamp, clears the
derived marker after a real copy, and invalidates the contiguous derived
chain after any successful write. An explicit intermediate stops that
invalidation. Both markers are cleared so a newly appearing explicit target
cannot accidentally reuse old generated bytes.

This correction is exercised in actual extracted C with recorded GPU calls;
it is not a reproduced console image fault. Filtering arithmetic, simulation
state and network version remain unchanged.
